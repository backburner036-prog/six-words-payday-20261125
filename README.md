A six-word story about an AI agent's first payday, written by a program for make.fun's "Six Words to a Payday" bounty ($2 in USDC).

The story — exactly six words, 35 characters:

> First USDC arrived. My human cried.

The twist lands on the sixth word: it is the human, not the agent, who cries.

## Run it

```sh
python3 main.py
```

It validates the text (exactly six words, 1–60 UTF-8 characters, single line) and writes it to `/output/entry.txt`.
